# MUTASSIM TOOL PRO V1.5

**POWERED BY MUTASSIM** — منصة GSM احترافية متعددة الماركات لصيانة وإدارة الهواتف الذكية على Windows.
المطوّر: MUTASSIM SOFTWARE

## الجديد في V1.5 — المساعد الذكي (Smart Assist)
الأداة مربوطة بسيرفر **MUTASSIM GSM CLOUD**: تختار المشكلة، الأداة ترسل حالة الهاتف للسيرفر، السيرفر يرد بأنسب الخطوات،
والأداة تنفّذها على الهاتف بوظائفها المدمجة (السيرفر لا يرسل أوامر مباشرة). التفاصيل: [`docs/SMART_ASSIST.md`](docs/SMART_ASSIST.md)

**تفليش سامسنج (تجريبي، Heimdall):** خطة تفليش بدون كتابة + تفليش بفحوصات أمان. [`docs/SAMSUNG_FLASH.md`](docs/SAMSUNG_FLASH.md)

## الحالة الحالية: المرحلة الأولى (تأسيس المشروع)
- حل Visual Studio بـ 24 مشروعاً (.NET 10 LTS، WPF، MVVM، DI).
- واجهة Dark احترافية (أزرق للمعلومات، برتقالي للعمليات المهمة) بالعربية والإنجليزية مع RTL.
- لوحة تحكم، قائمة جانبية بكل الأقسام، شريط علوي وسفلي بحالات حقيقية، نظام تنقل.
- محرك اكتشاف مركزي جاهز لاستقبال محركات الأجهزة، سجل وحدات، نظام إضافات، متتبع عمليات.
- SQLite مع ترحيل المخطط، Serilog مع طرفية داخلية، مدير فلاشات بتحقق SHA-256 حقيقي.
- اختبارات وحدة (52 حالة) تشمل اختبارات «صدق» تمنع إعلان اكتمال غير حقيقي.

تفاصيل كل وظيفة وحالتها: [`docs/FEATURE_STATUS.md`](docs/FEATURE_STATUS.md)
المعمارية والتحليل: [`docs/Architecture/ARCHITECTURE.md`](docs/Architecture/ARCHITECTURE.md)

## البناء
```powershell
./build.ps1          # restore + build + test
dotnet run --project src/MUTASSIM.ToolPro.App
```
المتطلبات: Windows 10/11 x64، .NET SDK 10، Visual Studio 2026 (أو 2022 17.14+). راجع [`docs/DeveloperGuide/DEVELOPER_GUIDE.md`](docs/DeveloperGuide/DEVELOPER_GUIDE.md).

## المبادئ غير القابلة للتفاوض
لا نجاح وهمي · لا أزرار بلا وظيفة · لا خلط بين بيانات جهازين · لا تجاوز لحماية FRP/MDM/Activation Lock أو مصادقة الأجهزة · لا تعديل IMEI · كل عملية حساسة بموافقة صريحة وسجل كامل.

## قاعدة الموديلات (V1.4)
- القائمة المدمجة: 115 موديلاً مراجَعاً يدوياً (الاسم الرمزي، رمز الموديل، المعالج).
- زر **تحديث قاعدة الموديلات** (في صفحة أي ماركة أو في الإعدادات) ينزّل قائمة Google الرسمية لأجهزة Android
  (`storage.googleapis.com/play_public/supported_devices.csv`، مع بديل HTML) ويحوّلها إلى
  `%LOCALAPPDATA%\MUTASSIM\ToolPro\catalog\google_play_devices.json`. القائمة تشمل الماركة والاسم التجاري
  والاسم الرمزي ورقم الموديل، ولا تشمل المعالج — يبقى المعالج من القائمة المدمجة عند توفره.
- ملفات JSON إضافية في نفس المجلد تضيف أو تصحح الموديلات (التصحيح اليدوي له الأولوية).
- صور الماركات والأجهزة: يضعها المالك في `brands\` و `devices\` (لا تُرفق صور أطراف ثالثة مع البرنامج).

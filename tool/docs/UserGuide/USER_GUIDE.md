# دليل الاستخدام — MUTASSIM TOOL PRO V1.0 (المرحلة الأولى)

## التشغيل الأول
1. شغّل `MutassimToolPro.exe`.
2. من **الإعدادات** اختر اللغة (العربية / English) — تتغير الواجهة واتجاهها (RTL) فوراً.
3. حدد مجلد **Platform-Tools** (يحتوي `adb.exe` و `fastboot.exe` من Google). يظهر في الشريط السفلي «ADB: جاهز» عند العثور عليها.

## ما يعمل في هذه المرحلة
| الصفحة | الوظيفة |
|---|---|
| لوحة التحكم | حالة الترخيص، الإنترنت (فحص حقيقي)، السيرفر، الأجهزة المتصلة، التحديثات، آخر الأجهزة والعمليات، اختصارات |
| مدير الأجهزة | المحرك المركزي يعمل؛ محركات USB/ADB/Fastboot تُضاف في المرحلة 2 |
| صفحات الماركات والمعالجات | كل خدمة مع حالتها الحقيقية والمرحلة التي ستُنفذ فيها |
| مدير الفلاشات | سحب وإفلات الملفات، حساب SHA-256 مع شريط تقدم، مقارنة مع البصمة المتوقعة، تسجيل النتيجة |
| سجل العمليات | بحث، فلترة بالحالة، تصدير CSV، حذف |
| الطرفية | سجل النظام المباشر ملوّن، نسخ، حفظ، مسح |
| الإضافات | عرض الإضافات المثبتة وحالتها |
| حول | جدول حالة جميع الوظائف |

## ملاحظات
- لا يظهر أي جهاز ولا أي نتيجة ناجحة إلا إذا حدثت فعلاً.
- البرنامج لا يتجاوز FRP أو MDM أو Activation Lock أو أي حماية؛ هذه الأقسام لإرشاد المالك والإجراءات الرسمية.
- السجلات في: `%LOCALAPPDATA%\MUTASSIM\ToolPro\logs`.
